# StatCard

**Purpose.** A single metric. Figma: `stat card` (5:169).

**When to use.** To call out one number (distance, days, height).

| Prop | Type | Default | Notes |
|---|---|---|---|
| `label` | `string` | — | H2 |
| `value` | `string` | — | Numeral |

**Variants.** None. 230 × 230.

**Tokens.** `background/surface`, `text/primary`.

**Do.** Use whole numbers.
**Don't.** Put more than one value in a card.
