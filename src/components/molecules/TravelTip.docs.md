# TravelTip

**Purpose.** Editorial tip callout. Figma: `travel tip` (5:117).

**When to use.** One per section, for the single most useful piece of local knowledge.

| Prop | Type | Default | Notes |
|---|---|---|---|
| `children` | `string` | — | One or two sentences |

**Variants.** None. Description style in `text/brand`, max 460 px.

**Tokens.** `background/brand-subtle`, `text/brand`.

**Do.** Be specific: a time, a place, a number.
**Don't.** Use it for warnings (use ErrorMessage or feedback tokens).
