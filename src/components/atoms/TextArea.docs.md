# TextArea

**Purpose.** Multi-line field for questions and notes. Figma: `text_area` (4:33).

**When to use.** When the answer may be longer than one line.

| Prop | Type | Default | Notes |
|---|---|---|---|
| `label` | `string` | — | |
| `error` | `string` | — | As Input |
| `…textarea` | native attributes | — | |

**Variants.** default, error. Fixed 90 px box.

**Tokens.** As Input.

**Do.** Say what you want in the label ("Your question").
**Don't.** Use it for single values.
